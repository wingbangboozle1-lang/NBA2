Game Flow Framework

Game flow analysis projects how each game is likely to unfold: pace, shooting efficiency, turnovers, rebounding, free-throw rate, and the resulting script (blowout, close game, shootout, grind). These projections drive line origination and pick generation.

Component Metric Definition / Formula League Average Impact on Game Flow Source
Pace Possessions per 48 min (Tm Poss + Opp Poss) / (Tm MP / 5) ≈ 94.4 possessions Higher pace → more possessions → higher totals and more player prop opportunities NBA Stats Help FAQ
Four Factors Effective FG% (eFG%) (FGM + 0.5 × 3PM) / FGA — 40% weight in Dean Oliver's Four Factors; primary driver of offensive efficiency Basketball Reference Four Factors
Four Factors Turnover % (TOV%) TOV / (FGA + 0.44 × FTA + TOV) — 25% weight; fewer turnovers = more possessions and higher efficiency Basketball Reference Four Factors
Four Factors Offensive Rebound % (OREB%) OREB / (OREB + Opp DREB) — 20% weight; second-chance possessions extend offensive efficiency Basketball Reference Four Factors
Four Factors Free Throw Rate (FTR) FTA / FGA — 15% weight; free throws = efficient points + opponent foul trouble Basketball Reference Four Factors
PIE Player Impact Estimate % of total game events achieved by player/team Team >50% likely winning; player >10% above average High PIE correlates with winning (.948 correlation to team win % per NBA analysis) NBA Stats Help FAQ

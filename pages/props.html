Player props and prop combos

The pricing code exists and is unit-tested (negative-binomial tails, minutes-implied lines, copula combos). What does not exist is a single official player-level input in this repository, so every row is blank. The last row is the one number we can give: treating combo legs as independent mis-states the price by a factor, and that is a math fact, not an estimate.

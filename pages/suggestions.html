Site Improvement Suggestions

This section is dedicated to suggestions for improving the site and decision-making framework. Each suggestion should be reviewed and the best path chosen before implementing any changes. No suggestion is implemented without review.

Suggestion ID Category Suggestion Expected Benefit Effort Priority Status Review Notes
SUGG-001 Data Integration Connect live odds API (DraftKings, FanDuel, BetMGM, Caesars) for real-time line comparison. Enables originated-line vs. market-line edge detection for every pick. High High Proposed Requires API credentials and cost evaluation.
SUGG-002 Data Integration Connect official NBA play-by-play and box-score API for backtesting and minutes validation. Enables backtesting of all 8 strategy templates against historical seasons. High High Proposed NBA official stats API endpoint needs identification.
SUGG-003 UI / UX Add a toggle between "Dashboard" and "Detailed Analysis" views on each page. Improves decision-making by letting users choose summary vs. depth. Low Medium Proposed Simple CSS/JS toggle; no data impact.
SUGG-004 UI / UX Add color-coded confidence indicators (High/Medium/Low) on pick cards. Faster visual triage of picks; reduces decision fatigue. Low Medium Proposed Confidence thresholds need definition.
SUGG-005 Feature Add a "correlation heatmap" showing which player props correlate within each game. Prevents correlation trap parlays; identifies +EV correlated combinations. Medium High Proposed Requires historical prop outcome data.
SUGG-006 Feature Add email/Slack alerts for injury status changes (Out → Questionable → Available). Ensures picks are voided or adjusted before game time when injuries change. Medium High Proposed Requires notification service integration.
SUGG-007 Feature Add backtesting results dashboard showing win rate, ROI, and edge per strategy. Quantifies skill vs. luck; identifies which strategies pass validation over time. High High Proposed Requires historical data + pick logging.
SUGG-008 UI / UX Add a mobile-responsive navigation drawer (sidebar collapses on mobile). Improves mobile usability for checking picks on game day. Low Low Proposed Already partially styled; needs JS toggle.

Review process: Any change to the site must be proposed here first, reviewed for impact on data integrity and verification standards, and approved before implementation. Suggestions marked "Proposed" are not yet implemented.

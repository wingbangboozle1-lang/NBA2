Picks are generated for every upcoming slate up to 3 days in advance using our originated lines.

Verification stance

How data is verified

  • Every table row that states a value carries a source link to an official, verified, trusted site (NBA.com or NBA-owned CDN).
  • If a value cannot be confirmed from an official source, it is left blank and flagged unverified.
  • Nothing is inferred or filled in. No odds, lines, correlations, or player projections are invented.
  • Betting lines and odds are not published by the NBA, so all wagering values are left blank and flagged unverified pending a licensed sportsbook data source.
  • Manual input required from you: none. All entries were researched and written by this session.

# NBA2

Originated NBA lines, strategy signals, and verified picks — collected, organized, and analyzed with every value sourced from an official site or left blank and flagged unverified.

## What this is

NBA2 collects, organizes, and analyzes **originated NBA lines** and strategy signals for **single bets, parlays, and player-prop bet combos**. It operates as a leaderboard competition that rewards top-performing strategies. Each strategy must pass validation gates, correlation values are determined, and the design removes luck so strategies are selectively skill-based. Picks are generated for every upcoming slate up to a maximum of 3 days in advance using originated lines. Injury impact on rotation minutes and production, plus game-flow analysis, are tracked.

## Verification policy

- Every table row that presents a value carries a source link to an official site.
- If a value cannot be confirmed from an official source, it is left **blank** and flagged **unverified**.
- Nothing is inferred or filled in.
- Flagged/unverified items do **not** block the merge; they are published on the Flagged for Review page.

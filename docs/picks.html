Slate picks (≤ 3 days ahead)

The generator produces picks for every game on an upcoming slate within a maximum 3-day window, using our originated lines. It is live code with hard-coded safety rules — and today it correctly emits zero real picks, because no strategy has passed its gates and no data feed is connected.

Real picks: BLOCKED (correct behavior). Two unlock conditions, neither met yet: (1) at least one strategy flips to active after passing all its gates out-of-sample (gates); (2) schedule / injury / odds feeds are connected (Flagged I-2). The ≤3-day window is enforced in code — a slate file containing anything beyond T+3 makes the generator refuse to run.

Running it

# demo (synthetic, safe):
python3 tools/generate_picks_lab.py --demo

# real mode (only meaningful once feeds exist and a strategy is active):
python3 tools/generate_picks_lab.py \
  --slate data/slate.csv --lines data/lines.csv \
  --injuries data/injuries.csv --corr data/correlation.csv \
  --out data/picks/

Slate window rule: the tool exits with an error if the slate file contains any game beyond today + 3 days — the 3-day maximum is enforced, not advisory (see the check).

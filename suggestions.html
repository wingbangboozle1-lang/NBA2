Suggestions

Site-improvement suggestions and a dedicated review path. Changes are reviewed and chosen before any implementation — nothing is deployed straight from this list.

Process

Review-before-implement path

  1. Submit: A suggestion is added to the table below (category, description, expected benefit, owner, proposed date).
  2. Review: A reviewer evaluates feasibility, data needs, verification impact, and priority.
  3. Choose: The reviewer selects the best path — implement, revise, defer, or decline — and records the decision.
  4. Implement (only if chosen): Approved changes are implemented on a feature branch, verified, then merged via pull request.
  5. Verify: After implementation, the change is re-verified against official sources where it states values.
Rule: No suggestion is implemented directly from this page. Each must pass the review steps above before any code or content change is made.

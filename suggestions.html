Suggestions
A dedicated section for suggestions to improve the site and decision making. Review each suggestion, choose the best path, then implement. No suggestion is applied automatically.
Process: someone reviews each suggestion, chooses the best path, and only then implements a change. Suggestions are logged here first and are not implemented by default.

Site-improvement suggestions (for decision making)

SUGG-001

Integrate a sportsbook market source for lines and odds

All betting-line values are blank because NBA.com does not publish odds. Connect an accessible licensed-sportsbook source (or an odds API) so originated lines can be compared to market lines and validation gate GATE-03 can be evaluated.

Impact: high • Owner: data/engineering • Path: choose a source, confirm access, add line table, mark verified/unverified per value.
SUGG-002

Integrate an official injury-report source

nba.com/injuries returned "Content Unavailable." Find an accessible official injury endpoint (NBA.com stats API or team injury reports) so rotation-minutes and production-impact values can be verified and fed into picks.

Impact: high • Owner: data/engineering • Path: locate source, test fetch, populate injuries.html, flag unverified values.
SUGG-003

Extract the 2026-27 standings table

The standings page exists but its table is JavaScript-rendered and was not captured. Use the official NBA stats API or a static standings export so team W/L records are verified.

Impact: medium • Owner: data/engineering • Path: call standings endpoint, parse W/L, update standings references.
SUGG-004

Confirm Nov 14 and Nov 15 matchups

Only game counts were extracted for those dates. Fetch the official schedule for each date so picks can be generated for the full 3-day window.

Impact: medium • Owner: data/engineering • Path: fetch schedule for 11/14 and 11/15, list matchups, mark verified.
SUGG-005

Build and validate strategies against all gates

No strategy has passed GATE-01–GATE-07. Define signal logic, compute correlation values, and run the gate evaluation log before emitting any pick.

Impact: high • Owner: strategy/quant • Path: implement STRAT-001/002/003, run gates, record results.
SUGG-006

Add a pick ledger with outcomes

Track every emitted pick, its strategy, line, result, and whether it was validated, so the leaderboard rewards genuinely top-performing strategies.

Impact: high • Owner: product/engineering • Path: add ledger table, outcome column, leaderboard ranking.
SUGG-007

Add a "review before implement" gate for site changes

Require that any change to the site or data be reviewed against this suggestions list and approved before deployment, so unverified values are never silently filled in.

Impact: medium • Owner: product • Path: add change-review checklist to deployment process.

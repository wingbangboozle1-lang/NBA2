What is actually proven

Every earlier version of this repository published a model and a leaderboard but zero graded outcomes. This report grades the model against 155 official NBA.com final scores, point-in-time, and reports what survives.

The honest headline: the originated line beats a constant line on margin error, but it is statistically indistinguishable from the trivial "pick the team with the better point differential" rule (model 62.6% vs better-record 64.0%, difference -1.44%, p = 0.90). No strategy is promoted and no reward is paid. That is the system working, not failing.

What changed in this session

  • Official results history captured. 155 games, 2026-10-20 → 2026-11-12, each with its own nba.com/game/<id> URL. This is the missing input every prior page cited.
  • Records reconstructed and checked. Team W-L rebuilt from final scores alone matches 70/70 official post-game records exactly.
  • Walk-forward, leakage-tested. No game is graded using information from its own date. The check is automated, not asserted.
  • Luck separated from skill. Wilson intervals, a permutation test, a naive-rule control and an explicit power calculation — so "not enough data" is a number, not an excuse.
  • Correlations measured, not assumed. The margin↔total premise behind the same-game parlay strategy is not supported: r = -0.0089 (95% CI -0.1663 to 0.149).
  • Gates re-run on evidence. G-04 (accuracy vs baselines) passes its registered wording only against an unshrunk strawman and is disputed; G-07 (walk-forward) now has real numbers and PASSES.

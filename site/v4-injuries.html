Injury releases

Stored official injury releases with revision and retrieval stamps, and the mechanical diff between consecutive ones.

Every release is stored with three stamps and one hash. The revision time is the time printed in the release's own header; the retrieval time is when this session read it; the index check is when the official index was last consulted for a newer file. The hash is over the transcribed text. The PDF bytes are not stored — bash egress to ak-static.cms.nba.com is blocked in this sandbox and the page tool renders PDFs as text — and that gap is flagged rather than glossed (F-V4-01).

The two clocks on the league's own site

Measured this session: the three /stats/teams/* pages report games through 2026-11-17, and /standings includes the games of 2026-11-18. They are one date apart. This build uses the stats-page W for the luck calculation (so the win column matches the games-played column) and publishes the gap, rather than silently mixing the two.

How each input was read

platform page-fetch transport, server-rendered HTML converted to markdown; the sandbox has no TLS egress to nba.com and a GitHub runner cannot read stats.nba.com (data/raw/egress_probe.json). This is recorded because it is a limitation: a reader cannot reproduce the read from this sandbox, only from an environment with page-fetch access. Everything described has a URL, and the three arithmetic identities in nba2/v7/test_v7.py are what make the transcription checkable.

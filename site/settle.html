The rule this page follows

A game is settled only when a committed, official final covers it AND, where a period row was captured, that row sums to the final. Ungraded is not a loss and is never imputed. The stamp is the end of the latest graded game day.

Hit rate alone is not evidence. p_observed_run_under_model is the probability, under the seal's own probabilities, of the exact run of winners observed. If that number is not small, the run is luck.

The seal files are never rewritten; the settlement is written beside them. Re-derive with python -m nba2.v4.settlement, which prints each seal's recomputed digest and the settlement's own digest.

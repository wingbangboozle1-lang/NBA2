The brief asks for every injury PDF, stored with its timestamp. This table is the inventory that makes that claim checkable: a release counts as known if a committed document cites its official URL or its bytes are in data/raw/pdf/. Twelve of the sixteen are not archived as bytes — flag F-F5-03. The ingester that closes that gap exists (nba2/v6/injury_backfill.py) and runs from a GitHub runner, where ak-static.cms.nba.com answers HTTP 200; it cannot run from a build sandbox, where the same request is TLS-reset. A release the league has since taken off the CDN will be recorded as unreachable with its HTTP status — the gap is the evidence, and no substitute file is ever written.

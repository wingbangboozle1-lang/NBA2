Leakage audit — three direct tests

A forecast that can see its own result is not a forecast.
Test Result What it shows Source
Same-date isolation PASS max within-date difference 0.0 results
No in-sample term PASS every rating, σ and baseline computed from strictly earlier dates results
Future-only edit PASS a fabricated game 30 days later moves no earlier forecast (max Δ 0.0) results

A rejected test, recorded so it is not proposed again. delete-the-target-game. It fails on any correct implementation because removing a row also removes it from later dates' volatility estimates. Recorded here so the same wrong test is not proposed again.

This repository ran that test first and it failed on a correct implementation. The failure was reported as a gate failure for one revision of this build. It is now explained here rather than deleted, because a test that fails for the wrong reason is a bug in the test.

Skill attribution — the two estimators, where they disagree

On the 19 games where A and B favour different clubs: A was right 6 times, B was right 13 times. An exact McNemar test gives p = 0.1671.

the second estimator is not separable from the first

Permutation test on the margin error

the model's margin error is distinguishable from a tie guess (see the sign of observed_mae_gain: negative means WORSE than predicting a tie)

p = 0.0002 over 4000 permutations, seed 20261115. The sign matters: the gain is -0.358, so a small p here means the model is reliably worse than a tie, not better.

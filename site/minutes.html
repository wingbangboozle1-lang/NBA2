Why there is no observed injury-replacement delta

Measuring who actually absorbed the minutes when player X was out needs at least two captured games for the same club, one with X and one without. This window contains exactly one captured game per club, so that column would have to be back-solved from a single game and is left — blank instead. The mechanical rule the site published before this session stays in place as the labelled fallback until a second game day is captured.

Gates applied to every team-game

  • minutes_sum — player minutes must sum to 240:00 + 25:00 per OT (+/-2s for the PDF's own rounding)
  • points_sum — player points must sum to the official final score (exact)

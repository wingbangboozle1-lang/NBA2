How to read the columns

  • A margin / B margin — the same game priced by two estimators that share no assumptions beyond the official results. If they differ by more than 2 points the row is graded C and the reason says so.
  • Disagree — the absolute gap. This is the primary confidence output: a wide gap means the line is an artefact of the method, not a reading of the game.
  • Total vs Naive avg — possessions × points-per-possession against the average-of-the-two-clubs'-scoring-averages. They are printed side by side because the brief asks for the second to be visible, not removed.
  • Availability — a count from the official injury report, disclosed on the row. The model is availability-blind: it prices the season-average club. An absence changes the number only through the minutes model, which is not filed for these clubs (FLAG-V3-ROTATION-UNFILED), so the column is a warning, not an input.
  • Grade — describes estimator stability only. A is the tight bar, B passes the minimum, C names a specific problem. It is not a confidence that the line wins.

Travel: what the number means and what it does not

The away club's travel is the great-circle distance from the venue of its previous game to this one, using the arena coordinate table. The home club's figure is 0 because it is at its own arena — not because it did not travel this week.

A club on a four-game road trip has accumulated travel that this per-game figure does not carry, so the column understates fatigue for long trips. A dash means the club has no prior game in the feed, which is unknown rather than zero.

What is withheld from this page

The market-anchored blend is withheld. The brief asks for the model line to be blended with the closing line, weighted by measured out-of-sample log-loss. No odds feed is connected, so there is no closing line to measure and no blend to compute. The weight formula is published on the methodology page with the two illustrative values a real market would produce; they are labelled illustrations and are not used here.

Read this first. The model can price a game; it cannot price a bet. A bet needs a price to beat, and no odds feed is connected to this build — so the picks page withholds all 27 games and prints the failing gate next to each. What is genuinely new in this build is the window and the provenance: the slate now covers the live three-day horizon (2026-11-14 → 2026-11-17) instead of the expired one it shipped with, and every priced row links to the official game page it was read from. The team table was re-read row by row from nba.com/standings and the three stats tables on 2026-11-14; the injury snapshot dates from 2026-11-13 and is published as such. See the verification log.

What this build cannot do — and why that is stated rather than hidden

Blocked inputs
Missing input What it blocks Where it would come from
Per-game margins and totals No official per-game result table is reachable from this build. stats.nba.com and cdn.nba.com return TLS errors and Basketball-Reference has no 2026-27 game log (HTTP 404). Required for: measured spread/total correlation, backtests, settling bets. basketball-reference.com/teams/LAL/2027_gamelog.html
Per-player game logs (minutes, usage, on/off) nba.com/stats player pages render season aggregates only for this client. Required for: minutes distributions, prop bet probabilities, injury replacement modelling. nba.com/stats/players/traditional
Market prices (spread, total, moneyline, prop lines) No licensed odds feed is connected and NBA.com renders odds client-side only. Required for: any value/edge claim, stake sizing, ROI, leaderboard scoring. nba.com/games

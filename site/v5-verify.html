The remaining 61 are absent from the active list of every captured game of their club — which is exactly what a report row predicting a player is out would look like, and is not a gap in the capture. Reproduce

python -m nba2.v5.check      # the eight gates, fail-closed exit code
python -m nba2.v5            # rebuild data/v5/*.json and the four pages
python -m unittest nba2.v5.test_v5 -v
The transcripts in data/v5/gamebooks_*.json are the official gamebooks read as text; the PDF bytes cannot be stored from this environment (F-V5-01). Everything downstream of them — the gates, the shares, the join — is recomputed from those committed files by the code in nba2/v5/, so any transcription error is reproduced and caught arithmetically rather than silently absorbed.

What this table is and is not. Each row is a subtraction of two measured averages over the window shown — it is not a fitted effect, it is not adjusted for opponent, and with one game played and one game missed it is a single paired difference. It is published because the brief asks for the replacement shares explicitly, and it is labelled with its own sample size so it is never mistaken for an estimate.

How to answer

Reply with the IDs you accept. Three answers are useful and one is not:

Accept

Named IDs become authorised work. The build gate then verifies the change actually happened, because each accepted item maps to a check in nba2/v2/check.py or a test.

Reject

A rejected item is removed from the queue and the reason recorded, so it does not quietly return in a later session wearing a new number.

Defer

Keep it, with the condition that would change your mind. A deferral without a condition is a rejection nobody had the nerve to write down.

Silence

Not an answer. An unanswered item stays awaiting owner decision and nothing is built from it.

The one decision that unblocks the others

Rank by cost of being wrong, not by effort.

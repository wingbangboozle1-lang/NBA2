Findings

What is genuinely good. The existing pipeline is unusually disciplined: 55 unit tests pass, a provenance lint proves all 915 published rows carry a source, the site is byte-for-byte reproducible from committed data, 22 predictions are hash-sealed, and 3,233 internal links resolve. That is a better foundation than most projects start with.
What is wrong. Six parallel site trees publish different numbers (root HTML, pages/, docs/, dashboard/, verified/, originated/). A reader has no way to know which one is current. The root page says "as-of 2026-11-13" while its own ledger is sealed at 22:51 that day, and the site still shows a snapshot several hours old on the next day.
What is missing, and blocks the brief. No market price, no per-game results, no player game logs. Those three absences are why the prior build could not produce a single settled bet, and they are why this build withholds all 31 picks rather than publishing confidence it cannot support.

What this session changed, and what it deliberately did not

All new work is in three new directories — nba2/v2/, data/v2/ and site/ — plus one appended block in COORDINATION.md. No file owned by another session was edited, so no earlier published output was destroyed. Where this build disagrees with an earlier one, the disagreement is on the verification page with both values shown.

Cleanup suggestions that are not this session's call

  • Consolidate to one published tree and redirect or delete the other five (needs an owner decision; see SG-18).
  • Untrack the 19 committed .pyc files: .gitignore already excludes them, so they are pure noise in diffs.
  • Reconcile the README's claim of 49 tests with the 55 that actually run.

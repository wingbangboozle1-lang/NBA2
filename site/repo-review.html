Freshness is not assured. The committed 183-game official-results history is a useful historical snapshot, not a live feed. The 2026-11-14 scheduled ingest archived injury reports but failed at the official-finals fetch before settlement or rebuild (F-043). The failure cause remains unverified; the Actions log download ended with EOF. A dated snapshot must not be described as currently fresh.
What still blocks full use. There is no licensed market-price feed, so no ROI, CLV, stake sizing or reward-bearing leaderboard is valid. Player game logs are missing, so player props, prop correlations and injury-driven minute/production impacts remain blank. The current automation also does not generate the next rolling three-day slate. These are separate gaps, not values to infer.

## 4. Findings that changed the product

1. **Expected wins now sum to actual wins** (174.0). The first calibration pass did not force that
   identity, so the per-team luck residuals summed to +1.19 instead of 0. A league intercept was
   solved for and the identity is now enforced by a unit test.
2. **No team is outside the luck band.** 0 of 30 teams have |luck z| > 1.96, so no team in this
   window can honestly be described as over- or under-performing its scoring level.
3. **The two independent ratings agree almost perfectly** (r = +0.999 across 30 teams; worst
   spread disagreement across 31 lines = 1.0 pt). That is evidence of stability, not of edge.
4. **Our own cover probability is 49.3–50.7% at our own number** — correct behaviour, and the
   reason a market price is required before any "pick" means anything.
5. **Every pick is withheld.** 0/31 published. Each names the failing gate (G6 no price,
   G7 no settled results). This is deliberate, not an omission.
6. **Six correlations that matter cannot be measured** and are listed with the exact missing
   dataset: spread-vs-total, margin-vs-team-total, player points-vs-rebounds, points-vs-assists,
   injury-to-teammate-usage, and the cross-game independence assumption.

## 8. Addendum — the backtest, and two findings that argue against this build

A parallel session (`arena/f7477d5e-nba2`, PR #30) landed **155 official final scores** in
`data/raw/history/` while this session was running. Those scores are enough to answer the question
this build had been unable to answer, so it was answered rather than deferred.

### Method (leakage control)

For every game on every date, ratings are rebuilt from **only** games strictly before that date.
No same-day result, no future result, no retro-fitted parameter. 16 opening-window games are
**skipped, not guessed**, because a team had never played. 139 games are scored.

The configuration (shrink prior 8 pseudo-games, home court 2.0 pts) is stated on the page and was
**not** tuned on the test set. A sensitivity table shows what other priors do — labelled as
sensitivity, not as selection.

### Result

| Measure | Value | Baseline |
|---|---|---|
| Straight-up accuracy | **66.91%** (93/139), Wilson 95% CI 58.7–74.2% | always-home 51.80% |
| Margin MAE | **11.91** | zero-margin baseline 13.27 (−10.2%) |
| Margin RMSE | **15.15** | 16.47 |
| Brier | **0.2184** | 0.2500 (−12.6%) |
| Log loss | **0.6275** | 0.6931 |
| AUROC | **0.7177** | 0.5 |
| Mean bias | **+0.26 pts** | 0 |
| Paired bootstrap on MAE gain | **+1.35 pts**, P(gain>0) = 0.999 (4,000 draws, seed 20261114) | — |

This is the first measured evidence of skill in the repository. It is **accuracy, not profit**:
no odds feed exists, so no ROI, no CLV and no leaderboard rank is claimable.

### Finding 1 — the margins are compressed (F-016)

| | Value |
|---|---|
| sd of predicted margins | **4.98 pts** |
| sd of actual margins | **16.43 pts** |
| ratio | **0.30** |
| r(predicted, actual) | **+0.390** |
| Spearman(\|predicted\|, \|actual\|) | **+0.102** |

The ratings rank teams usefully but cannot forecast magnitude. A predicted margin must never be read
as an expected margin and must never size a stake. The calibration slope (0.29 against a target of
1.00) is the same fact expressed on the probability scale: the probabilities bunch near 50%.

### Finding 2 — spread↔total is now measured, and is ~zero (F-017)

| | Value |
|---|---|
| n | 155 |
| r(margin, total) | **+0.0182** |
| 95% CI (Fisher z) | **[−0.1488, +0.1841]** |
| t (df 153) | **+0.21** |
| verdict | no detectable relationship at this sample size |

This number decides whether a same-game parlay is priced correctly, and it was previously listed as
**BLOCKED**. It is now published as measured — with the caveat that it proves nothing either way:
detecting a true r of 0.10 at 80% power would need roughly **780** games.

The independent recomputation of the parallel session's figure reproduces it exactly (they report
r = −0.0089 on 155 including the 16 ungraded games; restricting to the same 155 gives +0.0182 here —
both are inside the same CI, and the difference is a sample-composition artefact, not a disagreement).
Both values are on the site so a reader sees the sensitivity to which games are included.

### Integrity check added

Rebuilding every team's W-L from the 155 finals and comparing to the official card:
**0 teams exceed their official record**, and the total shortfall is exactly the 19-game hole on
2026-11-06 and 2026-11-11 that has no reachable official score. That is a second, independent
corroboration of the 30/30 W-L finding above.

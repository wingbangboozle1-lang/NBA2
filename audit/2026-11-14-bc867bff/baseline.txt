105/166 = 0.63253 and 105/167 = 0.62874: both rates are correct for their own sample. They differ
because a push is a no-decision against the spread and is excluded from ats.n, while the same game
remains in the straight-up sample. The predicate required the two rates to be equal, so it can only
ever fail a table that contains a push. This is a checker bug, not a data bug: no published number
is wrong, and no number was changed to make it pass.

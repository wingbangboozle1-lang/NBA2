## Transcription convention (read this before using the table)

The PDF's own column order is
`Game Date | Game Time | Matchup | Team | Player Name | Current Status | Reason`.
It prints the team/matchup cells only on the first page of a team block, and the text extraction
sometimes drops the leading Game Date / Game Time cells on continuation pages. To keep the table
mechanically parseable **every row below has all seven columns**, and a cell the extraction did not
carry is written as `—`. `—` means *the source text did not print it here*, never *zero* and never a
guess. A `(carried)` suffix marks a team cell that is empty on the page and is being continued from
the previous block; the suffix is this transcription's annotation, not an NBA field.
